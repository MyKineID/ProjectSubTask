# ProjectSubTask

Repo ini tempat saya menyimpan project kecil dari subtask. Setiap project punya folder sendiri, jadi satu project tidak tercampur dengan project lain.

## Isi repo

- `kasir-toko-gibran/` berisi program kasir sederhana di terminal. Program ini mencatat barang yang dibeli, menghitung total dan diskon, lalu mencetak struk toko Gibran.

## Cara menjalankan satu project

Masuk ke folder projectnya, lalu jalankan file utamanya. Contoh untuk kasir:

```bash
cd kasir-toko-gibran
python main.py
```

## Cara menambah project baru

1. Buat folder baru dengan nama projectnya.
2. Taruh kode dan file pendukung di dalam folder itu.
3. Tambahkan `README.md` di dalam folder itu, berisi penjelasan singkat dan cara menjalankannya.
4. Tambahkan satu baris tentang project itu di daftar isi repo di atas.
