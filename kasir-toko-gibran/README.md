# Kasir toko Gibran

Program kasir sederhana di terminal. Program ini meminta nama pembeli, mencatat barang yang dibeli, lalu mencetak struk dengan total, diskon, dan jumlah yang harus dibayar.

## Barang dan harga

- Indomie: Rp 3.500
- Telur: Rp 2.500

## Diskon

- Total Rp 100.000 atau lebih: diskon 10%
- Total Rp 50.000 sampai Rp 99.999: diskon 5%
- Total di bawah Rp 50.000: tidak ada diskon

## Cara menjalankan

```bash
python main.py
```

Ketik `1` untuk indomie, `2` untuk telur, dan `0` untuk berhenti lalu mencetak struk.
